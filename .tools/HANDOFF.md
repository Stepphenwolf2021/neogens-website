### CSS อยู่ที่ไหน — ไม่สมมาตร ต้องรู้ก่อนเพิ่มกฎใหม่

`split_css.mjs` ถอดออกไฟล์ร่วมได้เฉพาะกฎที่ซ้ำกันตั้งแต่ 80% ของหน้าในภาษานั้น ผลคือ

```
ฝั่งไทย   assets/site.th.css  30 KB  หน้าเหลือ inline 0–3 KB
ฝั่งอังกฤษ assets/site.en.css   4 KB  หน้ายังเก็บ inline ไว้ 19–31 KB ต่อหน้า
```

และมี **11 หน้าที่ไม่ได้ลิงก์ไฟล์ร่วมเลย** เก็บ CSS ไว้ในตัวเองทั้งหมด
(`coffee-demo` `coffee-farmer` `mkm-for-coffee` `privacy` `seo-as-knowledge-management`
`long-read-museums-and-libraries` และคู่ไทยของสี่ตัวแรก)

**กฎที่ตามมา สำหรับกฎ CSS ใหม่ที่ต้องมีผลทั้งเว็บ**

1. ใส่ในไฟล์ร่วมทั้งสอง **และ** ฝังในหน้าที่ไม่ได้ลิงก์ ทั้งสองอย่าง
2. ตั้ง specificity ให้สูงกว่ากฎที่จะไปชนใน inline เช่นใช้ `.nav-links .sub a` ไม่ใช่ `.sub a`
   เพราะบล็อก inline อยู่หลังไฟล์ร่วม ถ้า specificity เท่ากัน inline ชนะ
3. แทรกที่ `</style>` ตัวท้ายที่ยังอยู่ใน `<head>` **ไม่ใช่ตัวท้ายของไฟล์**
   บทความยาวมี `<style>` อีกก้อนซ้อนอยู่ใน `<svg><defs>` ซึ่งเป็นคนละ namespace
   กฎที่ตกในนั้นไม่มีผลกับหน้า — เจอจริงตอนวัดด้วย jsdom ไม่ใช่ตอนอ่านโค้ด
4. **ห้ามตัด CSS ด้วย regex ถ้ากฎนั้นอาจซ้อนชั้น** `@media` ซ้อนอีกชั้น regex จึงตัดพลาด
   ให้ไล่นับปีกกาแทน ดู `rules_of()` ใน `split_coffee.py` และดูข้อ 11 ของ `LESSONS.md`
   ว่าความพลาดนี้หน้าตาเป็นอย่างไรตอนขึ้นเว็บจริง
   `check.py` มีด่านนับปีกกาในบล็อก `<style>` ทุกหน้าแล้ว ตั้งแต่ 08-23

## Constraints

**Hard**

- **อ่าน `.tools/LESSONS.md` ให้จบก่อนพิมพ์ตัวอักษรแรกของเซสชัน** แล้วขึ้นต้นข้อความแรกด้วย `อ่าน .tools/LESSONS.md แล้ว — N ข้อ` ตอนนี้ N คือ 11
- **ข้อความที่ Noppadol เขียนมาเอง ห้ามแก้แม้แต่ตัวเดียว** รวมทั้งตัวสะกดที่ดูเหมือนพิมพ์ผิด เห็นอะไรที่ควรแก้ ให้ถามก่อนแล้วรอคำตอบ
- ใช้ `git --no-optional-locks` กับ `status` และ `diff` เสมอ และเช็กว่า `.git/index.lock` ไม่ค้างก่อนบอกว่างานเสร็จ
- Claude แก้ไฟล์อย่างเดียว ไม่ commit ไม่ push ไม่ deploy เอง
- แก้ copy ที่ไหน ต้องแก้อีกภาษาให้ตรงกัน และเช็ก `<title>` `meta description` `og:description` `alt` `aria-label` `placeholder`
- ห้าม letter-spacing ติดลบในกฎ CSS ที่มีข้อความไทย · line-height ไทยอยู่ที่ 1.75–1.9
- ห้ามใส่ตัวเลขสถานะระบบที่ยืนยันไม่ได้ · ห้ามใส่ชื่อฐานข้อมูล เฟรมเวิร์ก หรือสถาปัตยกรรมภายในบนเว็บ
- หน้าไหนอ้างตัวเลขในเนื้อหา ให้สคริปต์นับจากไฟล์จริงทุกครั้งที่รัน แล้วหยุดถ้าไม่ตรง ดู `FACTS` กับ `live_facts()` ใน `build_evidence.py`

**Soft**

- ภาษาไทยของ Neo Gens ใช้สกิล `neogens-thai-voice` เมื่อ Claude เป็นคนเขียน · ห้ามลงท้าย ครับ ในเนื้อความ · เขียนจากความคิด ไม่แปลจากอังกฤษ
- เนื้อหาใหม่ให้สั้น กระชับ เข้าประเด็น
- แก้ทั้งไซต์ด้วยสคริปต์ที่เก็บไว้ใน `.tools/` แล้วตรวจด้วย diff ระดับข้อความที่มองเห็น
- ด่านตรวจทุกชุดต้องมีทั้งข้อ *มีครบ* และข้อ *ไม่เหลือ*
- ประหยัด context — กรองผลก่อนดึงเข้ามา อย่าเปิดไฟล์ HTML ทั้งไฟล์ (ไฟล์ละ 27–186 KB)

## สั่งงานจากมือถือระหว่างเดินทาง

`remote.command` ที่รากรีโป — ดับเบิลคลิกแล้วปล่อยหน้าต่างเปิดค้างไว้ เซสชันรันบนเครื่องนี้
มือถือเป็นแค่หน้าต่างเข้ามาสั่ง เปิดแอป Claude แตะแท็บ Code แล้วเลือก **Neo Gens website**

- ใช้โหมด interactive ไม่ใช่ server mode เพราะ server mode เลิกเองหลังเน็ตหลุดราวสิบนาที
- มี `caffeinate` กันเครื่องหลับ และ loop เปิดใหม่ให้เองถ้าโปรแกรมหลุด
- **แจ้งเตือนบนมือถือต้องเปิดตามลำดับ** เปิดเซสชัน แล้วเชื่อมมือถือให้ติดก่อน จากนั้นค่อยพิมพ์ `/config` บนเครื่อง สองตัวเลือก `Push when Claude decides` กับ `Push when actions required` จะโผล่ก็ต่อเมื่อ Remote Control ทำงานและมือถือลงทะเบียนแล้ว ถ้าขึ้น `No mobile registered` ให้เปิดแอปบนมือถือค้างไว้แล้วรอเชื่อมรอบใหม่
- ปิดหน้าต่าง Terminal เมื่อไร เซสชันออฟไลน์ทันที
- Claude ยังไม่ commit ไม่ push ตามกติกาเดิม ถ้าต้องการให้ deploy แทนระหว่างเดินทาง ต้องสั่งให้ชัดในเซสชันนั้น
